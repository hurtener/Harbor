# event-viewer-ts

The TypeScript sibling of [`../event-viewer`](../event-viewer) (the Go
worked client). It tails one session's Server-Sent-Events stream from a
running Harbor Runtime, using wire types **vendored from a generated
module** — no Console import, no hand-transcription.

This is the answer to *"where does a non-Console TypeScript client get
typed wire shapes?"*: copy-vendor one generated file.

## The generated module

`harbor-protocol.gen.ts` is generated by `cmd/harbor-protocol-ts-types`
from the canonical Harbor Protocol single sources
(`internal/protocol/{types,methods,errors}` + the canonical event-type
set). It carries:

- a TypeScript `interface` for every canonical wire type
  (`RuntimeInfo`, `StartRequest`, `IdentityScope`, …),
- string-union types for the method / error-code / event-type name sets
  (`HarborMethod`, `HarborErrorCode`, `HarborEventType`),
- the pinned `PROTOCOL_VERSION` and `WIRE_SURFACE_DIGEST` constants.

It carries **no client logic** — only types — so you copy it into your
own client and write your transport against it. Regenerate / re-vendor
after a Harbor upgrade:

```sh
make protocol-ts-types-gen
```

`make protocol-ts-types-gen-check` is the CI gate that fails if the
committed module drifts from the Go wire surface. The module is
independent of the Console's hand-maintained `web/console/src/lib/protocol.ts`
and of the Console wire manifest; it does not touch either.

## Run it

No install step — Node ≥ 22.6 strips the TypeScript types in place:

```sh
harbor dev &
node --experimental-strip-types event-viewer.ts
```

Or with a TypeScript runner you already have:

```sh
npx tsx event-viewer.ts
```

### Environment

| Variable | Default | Meaning |
|---|---|---|
| `HARBOR_BASE_URL` | `http://127.0.0.1:18080` | Runtime base URL |
| `HARBOR_SESSION` | `event-viewer-ts` | session to tail |
| `HARBOR_TOKEN` | *(dev bootstrap)* | bearer token; omitted ⇒ loopback dev-bootstrap mint (`harbor dev` only) |
| `HARBOR_PROBE` | *(unset)* | `1` ⇒ do the `runtime.info` handshake, then exit 0 |
| `HARBOR_STREAM_SECONDS` | `0` | tail for N seconds then exit 0 (`0` = until interrupted) |

## Type-check

```sh
npm install --no-save typescript @types/node
npm run typecheck
```

(`typescript` / `@types/node` are dev-only; nothing is committed — the
client itself has zero runtime dependencies.)
